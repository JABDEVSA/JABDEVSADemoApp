# Initial visual baseline

Data Detective: midnight-navy sidebar, warm-white workspace, emerald primary actions, understated borders, Inter/system sans-serif, generous spacing. Brand mark: four-cell teal lens. Desktop sidebar 236px; collapses on narrow screens. Top header contains breadcrumbs and session identity. Analytics use summary cards, clear chart labels, bordered tables, explicit pagination, and readable status badges. Sample cards differentiate retail, subscriptions and logistics. Login/register use a focused accessible dialog. No existing approved app was present; this first implementation is pending CTO visual review.

Main views: Overview, Data workspace (Overview / Explore data / Clean & export), How it works. User datasets stay private. Explain failures in context, preserve form input and show loading states. Keyboard focus remains visible. All data mutation and analysis occur via the API.
